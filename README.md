# eBay userscripts

Small [Tampermonkey](https://www.tampermonkey.net/) scripts that make eBay less annoying.

| Script | What it does | Install |
| --- | --- | --- |
| **Hide eBay Live** | Removes eBay Live everywhere it shows up: the nav tab, the homepage live-stream carousel, the "Grow your business with Live" banner slide and the Live tile in Popular destinations. | [Install](https://raw.githubusercontent.com/JA-Marshall/ebay-userscripts/main/ebay-hide-live.user.js) |
| **Card labels** | Lets you name each saved card at checkout (`x-1234` → "Business"), so you stop guessing which card is which. Click **+ label** next to a card to set or change its name. Labels are kept in Tampermonkey's storage on your machine and never leave it. | [Install](https://raw.githubusercontent.com/JA-Marshall/ebay-userscripts/main/ebay-card-labels.user.js) |

## Installing

1. Install the Tampermonkey extension for your browser.
2. Click an **Install** link above. Tampermonkey opens an install page; click **Install**.

Tampermonkey checks this repo for updates, so fixes arrive on their own.

Works on eBay UK, US, DE, FR, IT, ES, AU, CA and IE. Card labels works on the UK and US checkout (`pay.ebay.co.uk`, `pay.ebay.com`).

## When eBay changes its pages

These scripts match eBay's current markup. If something comes back or stops working, open an issue with a screenshot.
